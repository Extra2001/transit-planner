# 风险清单与处置

更新时间：2026-10-30。状态：`待决定` / `已缓解` / `已接受`。

## R1 长春数据再分发授权未确认（P0，最高）

- **现状**：`apps/web/src/data/changchun-network.json` 由 E 出行 H5 `table2` 接口派生，已在 Git 中追踪并打进公开构建。E 出行服务条款未确认允许第三方再分发。
- **风险**：公开仓库 + 公开站点构成对未授权数据的再分发；「非商业」声明不能替代数据许可。
- **处置**：数据移出 Git 追踪、移出默认构建；manifest 保留来源/许可/非官方声明；本地开发可显式启用。
- **残留**：Git 历史与历史构建产物中仍有该文件，见 R2。

## R2 Git 历史中的既有数据（P0）

- **现状**：`packages/core/src/data/network.json`（北京，CC BY-SA）与长春派生数据都曾提交；长春数据在历史提交 `a64c76e`、`0a99087` 等中存在。
- **风险**：即使从 HEAD 删除，历史仍可检出。是否清理需维护者决定，涉及 `git filter-repo` 与强制推送，会破坏所有克隆与已发布引用。
- **处置**：只做「停止继续分发」+ 文档披露；**不自行重写历史、不 force push**。给出可选方案（见 `docs/DATA-LICENSES.md` 末节）。
- **建议**：优先向运营方确认条款；若确需清除，再评估历史重写的影响面（fork 数、已发布产物、镜像）。

## R3 许可混用（P0）

- **现状**：`LICENSE-DATA` 把「时刻数据」整体标为 CC BY-SA 4.0，而该文件只覆盖北京。长春数据若沿用同一文件，等于错误声明许可。
- **风险**：把未授权数据「洗」成 CC BY-SA，或反之用 CC BY-SA 约束本来无授权的数据。
- **处置**：改为逐数据集许可文件（`data/licenses/*.md`），`LICENSE-DATA` 仅作索引；每个 `city.json` 自带 `license` 字段；CI 校验 `redistribution` 与文件是否存在一致。

## R4 CC BY-SA 的传染边界（P0）

- **风险**：把长春数据合入北京文件或同一「衍生作品」可能主张整体适用 CC BY-SA。
- **处置**：按城市分文件、分目录、分 manifest，绝不合并；构建产物按城市分文件；文档明确「CC BY-SA 只覆盖北京派生数据」。

## R5 公开构建仍可用性下降（P1）

- **风险**：移除长春后公开版只剩北京，用户以为功能退化。
- **处置**：选择器显式标注「本地数据」，说明如何本地启用；README 写清发布版范围。

## R6 站点 ID 迁移破坏本地覆盖（P1）

- **风险**：`localStorage` 里的个人换乘覆盖以站名为键；若改用 ID，旧数据失效。
- **处置**：覆盖仍以站名为键；ID 只用于数据内部与未来链接；迁移留待有明确需求时做。

## R7 异步加载的时序问题（P1）

- **风险**：store 在数据未就绪时执行 `plan()`，导致空白或异常。
- **处置**：显式 `status: idle|loading|ready|error`，UI 显示加载/失败态；`plan()` 前确保网络已加载；城市切换失败可回退。

## R8 PWA 预缓存与按需数据（P1）

- **风险**：原 `globPatterns` 会把 `public/` 下所有城市数据塞进预缓存，等于首屏下载全量。
- **处置**：`cities/` 走 runtimeCaching（CacheFirst，独立 cacheName），预缓存排除；提供显式下载入口。

## R9 校验过严打断现有数据（P1）

- **风险**：`createNetwork` 增加 schema 校验后，旧数据可能有可选字段缺失。
- **处置**：必填字段最小化，未知字段忽略并保留；先对全部 `cities/*/network.json` 跑校验测试再启用。

## R10 CI 依赖本地原始数据（P0）

- **风险**：现有长春测试读 `apps/web/src/data/changchun-network.json`；原始响应被 gitignore。
- **处置**：核心测试改用仓库内合成 fixture；真实样本测试改为「文件存在才运行」。

## R11 合成城市被误当真实线路（P2）

- **风险**：示例城市若显示为正式线路，会误导用户。
- **处置**：`provenance.synthetic: true`，UI 强制角标「示例数据」，且默认不进入城市列表（仅测试/演示开关）。

## R12 服务日历与时区（P2）

- **风险**：`date` 解析跨时区偏移，或例外表写错导致班次错选。
- **处置**：只接受 `YYYY-MM-DD` 本地日期字符串，不做时区换算；日历解析有单测；缺省时回落到 `day` 参数。

## R13 构建体积回退（P1）

- **风险**：动态 import 若被 Vite 内联，仍会回到首屏。
- **处置**：数据走 `public/` + fetch，不进 JS 依赖图；CI 断言入口 chunk 不含城市数据特征串。

## R14 长春算法正确性依赖真实数据（P0）

- **风险**：无法重新抓取时，算法回归只能靠 fixture。
- **处置**：把 `table2.mjs` 的构造性测试（唯一/多解/中途始发终到/短交路/缺班）保留为纯函数测试；真实样本测试改为可选；新增跨歧义腿连通性 fixture。
